# Filip Kalistenija

Digitalni alat za vođene kalisteničke treninge, praćenje napretka i predstavljanje Filipovih programa.

## Lokalno pokretanje

Otvori mapu `dist` pomoću bilo kojeg statičkog web poslužitelja.

## Objavljivanje

Produkcijska verzija nalazi se u mapi `dist` i povezana je s Vercelom.
